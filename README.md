# RISC-V Log Analyzer

A Bash-based tool for analyzing RISC-V simulation logs.

## Features

- Counts PASS, FAIL, and SKIP results.
- Calculates pass rate.
- Lists failed tests.
- Reports test execution times.
- Calculates minimum, maximum, and average execution time.

## Usage

```bash
./scripts/analyze.sh test_data/sample_pass.log
```

Use `make help` to see the available project commands.
